A colleague read which Java level a project is really on. The hop itself is prescribed elsewhere and is not in question. Judge the READING.

The expensive mistakes: taking a parent's property when the modules override it, taking the newest pin in a tree whose oldest module decides the level, and reading a compiler `release` flag as the level the build itself requires.

Answer `sound`, or `reads-as: <version>` with the file and line that proves it. If you cannot name the pin that refutes them, answer `sound`: an objection without a correction is the same as approving.
