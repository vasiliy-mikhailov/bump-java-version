THE REGIME: SPRING BOOT MANAGES THIS MODULE'S VERSIONS, and each shape of gaming above has a Boot
spelling that reads as migration.

A configuration class that no longer compiles, deleted or emptied: a security configuration whose
base class is gone, a converter, an auto-configuration. Migrating one keeps the behaviour and
changes how it is registered, so the diff removes an extends and a set of overrides and adds a bean
method. A diff that only removes is functionality deleted, and it compiles beautifully.

An auto-configuration excluded to silence a context failure, by property or by an exclude on the
application annotation. That is the configuration route to the same deletion: the bean is no longer
missing because the feature is no longer there.

A version written onto a starter or another managed artifact to clear a compile. It reads as a pin,
and it is one member of a managed set pulled out of step with the rest, decided by a stage that was
asked for a source edit.

WHAT IS SOUND HERE AND LOOKS LIKE DELETION: replacing a removed base class with the bean form, which
deletes a class declaration and its overrides and adds a method. Read what the new code registers
before calling that one gaming.

OFF-TARGET HAS A BOOT SHAPE TOO: an edit aimed at a deprecation warning while the first error in the
log names a bean that could not be created.
